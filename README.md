# Модульное Windows-приложение

Модульное Windows-приложение на C# с поддержкой динамической загрузки
плагинов (`.dll`) и асинхронного выполнения задач.

Проект разработан в рамках тестового задания.
`C#TestProjct\Host\Host\bin\Debug\net10.0-windows\Host.exe`

---

## Описание

Приложение представляет собой расширяемую систему выполнения задач.

Основное приложение (`Host`) отвечает за:

- загрузку плагинов;
- обнаружение доступных задач;
- отображение задач в пользовательском интерфейсе;
- получение параметров, необходимых для запуска задачи;
- асинхронный запуск задач;
- отображение текущих и завершённых задач;
- отображение результатов выполнения;
- отмену выполняемых задач.

Функциональность отдельных задач вынесена в независимые `.dll`-модули.

Благодаря такой архитектуре новые задачи можно добавлять в виде отдельных
плагинов.

---

## Архитектура
Проект разделён на несколько компонентов:
```bash
     Host(`WPF application`)
            |
      Contracts(`API`)
     |                     |
Plugins.File(`.dll`)  Plugins.Command(`.dll`)
```


## Host
Основное WPF-приложение.

Host не содержит прямой зависимости от конкретных плагинов.

Плагины загружаются динамически во время работы приложения.


## Contracts
Связующий модуль между Host и плагинами.

Содержит интерфейсы и модели, необходимые для взаимодействия:
```bash
IPlugin
ITask
TaskParameter
TaskResult
```


## Plugins.File
Плагин с файловыми задачами.

Содержит:
Поиск файлов по маске и стартовой директории.

Поиск последовательности байтов в файле.


## Plugins.Command
Плагин для выполнения Shell-команд.

Позволяет запускать внешние процессы без блокировки пользовательского интерфейса.

---

## Динамическая загрузка плагинов
`Host` автоматически ищет `.dll` в каталоге: 
```bash
  `Plugins/`
```
Например:
```bash
 `Host.exe
  Plugins/
     Plugins.File.dll
     Plugins.Command.dll`
```


При запуске приложения:

 - `Host` находит DLL-файлы.
 - Загружает сборки динамически.
 - Находит реализации `IPlugin`.
 - Создаёт экземпляры плагинов.
 - Получает список доступных `ITask`.
 - Отображает задачи в пользовательском интерфейсе.

---

## Доступные задачи

### Поиск файлов
Позволяет искать файлы по заданной маске начиная с указанной директории.

Пример параметров:

Маска: `*.txt`

Папка: `C:\Documents`

Результатом является информация о найденных файлах.


## Поиск последовательности байтов
Позволяет искать заданную последовательность байтов внутри файла.

Пример параметров:

Последовательность: `libsec`

Файл: `C:\Dumps\BigFile.bin`

Задача предназначена в том числе для поиска последовательностей
однобайтовых символов в бинарных файлах


## Выполнение Shell-команды
Позволяет запускать внешние команды операционной системы.

Пример параметров:

Команда: `ping`

Аргументы: `localhost`

Запущенный процесс выполняется асинхронно, поэтому 
интерфейс приложения остаётся рабочим.

---

## Асинхронное выполнение
Все задачи запускаются через асинхронный API:
```bash
Task<TaskResult> ExecuteAsync(
    Dictionary<string, string> parameters,
    CancellationToken cancellationToken,
    IProgress<double>? progress = null);
```

Это позволяет выполнять продолжительные операции без блокировки UI.

---

## Отмена задач
Для выполнения задач используется `CancellationToken`.

Это позволяет остановить поддерживающие отмену операции.

Для Shell-команд при отмене дополнительно завершается запущенный процесс.

---

## Пользовательский интерфейс
Интерфейс содержит:

 - список доступных задач;
 - информацию о выбранной задаче;
 - динамически создаваемые поля параметров;
 - кнопку запуска;
 - кнопку отмены;
 - список выполняемых задач;
 - историю завершённых задач;
 - статус выполнения;
 - результаты выполнения.

Поля параметров формируются на основании описания, предоставленного самой
задачей через ITask.Parameters.

Таким образом, Host не должен заранее знать, какие именно параметры
необходимы конкретному плагину.
